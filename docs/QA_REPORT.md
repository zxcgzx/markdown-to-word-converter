## 本次发现并修复的问题

### 命令搜索相关性

问题：输入“预览”时，描述中包含“预览”的低相关操作可能排在“切换到预览视图”之前。

修复：增加标签精确匹配、标签开头、标签包含、关键词和描述的分级权重排序。

### 分享码日期校验

问题：仅验证 `YYYY-MM-DD` 字符串格式时，`2025-02-31` 仍可能被 JavaScript 自动滚动成三月日期。

修复：按年、月、日构造截止时间后反向核对日历字段，拒绝不存在的日期。

### 专注模式焦点目标

问题：在预览-only 视图进入专注模式时，焦点可能仍被交给隐藏的编辑器。

修复：预览视图聚焦预览区域，编辑或分栏视图聚焦编辑器。

### 弹层焦点逃逸

问题：登录页和命令面板打开时，连续 Tab 可能进入背景页面。

修复：为登录入口和命令面板增加完整焦点循环，并在关闭命令面板时恢复原焦点。

### 持久存储不可用

问题：浏览器禁止 `localStorage` 时，“自动进入”写入失败可能影响正常登录反馈。

修复：登录流程与持久化结果解耦；当前会话继续进入，工作区仅显示非阻断提醒。

## 自动化方法边界

浏览器回归使用真实页面、真实 CSS 和本地应用脚本，但外部 CDN 依赖使用确定性行为桩。它可以验证：

- 布局与响应式；
- 指针命中；
- 键盘焦点；
- 页面状态；
- 公式与导出控制逻辑；
- 本地存储和会话流程。

它不能完全替代：

- 实际 CDN 可用性；
- KaTeX 字形像素级视觉比较；
- Microsoft Word 或 WPS 打开真实 DOCX 的端到端兼容性；
- 真实 AI 服务商网络请求；
- 外部图片服务器的跨域行为。

## 部署后仍需人工确认

1. GitHub Pages 或本地网络能够加载全部 CDN；
2. 浏览器缩放 90%、100%、110% 和 125% 时符合个人视觉偏好；
3. 用目标版本 Microsoft Word 或 WPS 打开真实导出的 DOCX；
4. 复杂分式、矩阵和多行公式仍是线性可编辑文本，不是 OMML；
5. 使用自己的 AI 接口、API Key 和模型完成一次真实请求；
6. 网络图片读取受来源服务器和浏览器 CORS 策略影响。
