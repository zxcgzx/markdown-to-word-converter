# v5.5 覆盖更新与验收指南

v5.5 同时修改了页面结构、设置、A4 预览、DOCX 导出、专业交付模块、样式、测试和文档。请整体覆盖仓库，不要只替换 `index.html`、`app.js` 或某一个 CSS 文件。

## 一、覆盖前先备份

虽然 v5.5 继续沿用 v5.4 的本地数据结构，但重要内容仍建议先保存到浏览器之外：

1. 下载正在编辑的重要 `.md` 文件；
2. 打开“设置 → 数据与诊断”；
3. 点击“导出完整备份”；
4. 保存生成的 JSON；
5. 记录自定义密码和 AI 设置。

API Key 默认不会写入备份，只有主动勾选“备份中包含 API Key”时才会包含。

## 二、正确覆盖方式

ZIP 解压后会得到：

```text
markdown-to-word-converter-fusion-v5.5/
```

把这个目录中的全部内容复制到仓库根目录，包括：

```text
index.html
css/
js/
tests/
docs/
.github/
package.json
README.md
CHANGELOG.md
```

本次新增的核心文件：

```text
css/professional.css
js/professional.js
tests/professional-v55.test.js
```

不要遗漏，否则“交付”工具、专业设置、封面、目录和分节功能不会完整加载。

## 三、提交与部署

```bash
git add .
git commit -m "Release v5.5 professional Word delivery"
git push origin main
```

仓库中已包含 GitHub Pages 工作流。推送到 `main` 后会继续自动发布。

## 四、发布后硬刷新

本地资源已统一使用：

```text
?v=5.5
```

若页面仍显示旧版，请执行：

```text
Windows / Linux：Ctrl + F5
macOS：Command + Shift + R
```

也可以在浏览器开发者工具中清除站点缓存后重新打开。

## 五、数据兼容

v5.5 继续使用：

```text
IndexedDB：md2word.workspace.v5.4
localStorage fallback：md2word.workspace.fallback.v5.4
设置：md2word.workflow.settings.v5.4
最后文档：md2word.workspace.last-document.v5.4
```

因此正常覆盖升级时：

- v5.4 文档继续存在；
- 版本历史继续存在；
- 图片素材继续存在；
- 主题、密度、页面设置和 AI 配置继续存在；
- v5.3 迁移逻辑仍保留；
- 旧数据不会因为打开 v5.5 而主动删除。

## 六、v5.5 专项验收

### 1. 密码入口

使用任一默认密码登录：

```text
basic123
517517
lingling
```

确认：

- 密码错误时有明确提示；
- Enter 可以提交；
- 登录后身份显示正确；
- 主题和本机自动进入设置正常。

### 2. 专业交付工具

点击顶部第二行的“交付”。

确认：

- 内联工具区正常展开；
- 可以选择交付方案；
- 封面、目录和标题编号开关可用；
- 可以插入下一节横向、下一节纵向和题注；
- “完整设置”能打开统一设置中的“专业交付”分类。

### 3. 封面

在“设置 → 专业交付”中：

1. 启用封面；
2. 填写作者、单位、版本和文档编号；
3. 切换 A4 预览。

确认：

- 第 1 页直接显示封面；
- 封面前没有多余空白页；
- 封面不显示正文页眉和页脚；
- 标题、副标题和元数据可见。

### 4. 自动目录

1. 文档中至少包含 H1、H2；
2. 启用自动目录；
3. 设置目录深度为 H1–H3；
4. 查看 A4 预览；
5. 导出 Word。

确认：

- A4 预览有目录结构；
- 目录后正文从新页开始；
- Word 中存在自动目录；
- 首次打开后按 Word / WPS 提示更新域，目录页码能够刷新。

### 5. 标题编号

选择：

```text
1 · 1.1 · 1.1.1
```

确认：

- 网页预览显示标题编号；
- Markdown 源码没有被直接写入编号；
- Word 标题使用多级编号；
- 插入、删除标题后可以重新计算编号。

### 6. 页眉、页脚和页码

示例：

```text
页眉：{number} · {title}
页脚：{version}
页码：第 1 页 / 共 12 页
```

确认：

- A4 预览能看到近似页眉和页脚；
- Word 页脚存在真正的当前页和总页数字段；
- 封面没有页眉页脚；
- 正文页码按设置对齐。

### 7. 局部横向分节

在宽表格前点击：

```text
下一节横向
```

在宽表格后点击：

```text
下一节纵向
```

确认：

- Markdown 中插入两个分节标记；
- A4 预览中只有中间页面横向；
- Word 中只有对应节横向；
- 后续正文恢复纵向。

### 8. 表格与题注

1. 插入一个 Markdown 表格；
2. 插入表题；
3. 启用表头跨页重复；
4. 启用避免表格行拆分；
5. 选择正式灰阶或学术表格样式。

确认：

- A4 预览显示题注；
- Word 表格样式正确；
- 第一行被识别为重复表头；
- 普通高度的行不会被轻易拆分。

### 9. 链接与书签

示例：

```markdown
# 第一章

[访问网站](https://example.com)

[返回第一章](#第一章)
```

确认：

- 外部链接在 Word 中可点击；
- 内部链接可以跳转到标题书签；
- 标题仍保持 Word 标题样式。

### 10. Word 导出成功回执

确认：

- 文件名与顶部文档名一致；
- 回执显示公式、表格、图片、封面、目录或分节信息；
- 复制文件名按钮正常；
- 回执不会阻塞继续编辑。

## 七、回归验收

### 公式

测试：

```latex
\[
\text{玻片–O–Si–(CH}_2)_3\text{–S–S–(CH}_2)_2\text{–NH–CO–C(Br)(CH}_3)_2
\]
```

以及：

```latex
(C_\eta=1%C_{\text{curtail}})
```

确认预览、诊断、源码定位和 Word 上下标没有回退。

### 图片

分别测试：

- 粘贴截图；
- 拖入本地图片；
- 网络图片；
- 删除未使用素材；
- 导出 Word。

### 多文档与历史

确认：

- 新建第二份文档；
- 切换文档；
- 创建手动版本；
- 恢复历史版本；
- 复制文档；
- 备份与导入。

### 响应式

至少检查：

```text
1440 px
1024 px
820 px
390 px
320 px
```

确认：

- 页面无横向滚动；
- Word 主按钮始终可达；
- 移动端不显示过多顶部按钮；
- 专业设置可以滚动；
- A4 页面在窄屏内缩放。

## 八、回退

回退前建议：

1. 使用 v5.5 导出完整工作区备份；
2. 下载所有重要 Markdown；
3. 恢复上一版本仓库文件；
4. 硬刷新页面。

v5.4 代码仍可以读取相同工作区数据库，但不会理解 v5.5 的专业交付设置。回退不会自动删除这些设置，重新升级后仍可能恢复。

## 九、真实环境注意事项

自动测试无法覆盖所有实际环境差异。部署后仍建议：

- 确认 CDN 依赖可以加载；
- 使用真实 Microsoft Word 和 WPS 各打开一次；
- 更新一次自动目录；
- 检查混合纵横向分节；
- 检查中文字体是否被本机字体替换；
- 测试一个允许 CORS 和一个禁止 CORS 的网络图片；
- 用真实 AI Key 完成一次请求。
